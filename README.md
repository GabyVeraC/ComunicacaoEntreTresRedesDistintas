# 🌐 Comunicação entre Três Redes com Cisco Packet Tracer

Projeto desenvolvido no **Cisco Packet Tracer** com o objetivo de simular a comunicação entre três redes IPv4 distintas, utilizando endereçamento baseado nas classes **A, B e C**.

A atividade tem como foco a prática de conceitos fundamentais de redes de computadores, incluindo endereçamento IP, máscaras de sub-rede, configuração de dispositivos e comunicação entre diferentes redes.

## 📌 Sobre o projeto

A topologia é composta por **três redes distintas**, sendo cada uma configurada utilizando uma faixa de endereçamento pertencente a uma classe diferente:

* **Classe A**
* **Classe B**
* **Classe C**

As três redes foram interligadas através de dispositivos de rede configurados para permitir a comunicação entre os diferentes segmentos.

## 🖥️ Topologia

A estrutura do projeto é composta por:

* 3 redes distintas
* Roteadores para interligação das redes
* Switches para conexão dos dispositivos
* Computadores/hosts
* Endereçamento IPv4

Cada rede possui sua própria faixa de endereçamento e configuração de rede.

## 📡 Endereçamento

| Rede   | Classe | Faixa utilizada                 |
| ------ | ------ | ------------------------------- |
| Rede 1 | A      | Endereço pertencente à classe A |
| Rede 2 | B      | Endereço pertencente à classe B |
| Rede 3 | C      | Endereço pertencente à classe C |

O objetivo é demonstrar que diferentes redes podem ser configuradas e interligadas, permitindo a comunicação entre dispositivos mesmo pertencendo a segmentos de rede distintos.

## 🔧 Configurações realizadas

Durante o desenvolvimento foram realizadas configurações como:

* Endereçamento IPv4 dos dispositivos
* Configuração das interfaces dos roteadores
* Configuração dos switches
* Definição das máscaras de sub-rede
* Configuração dos gateways
* Interligação entre diferentes redes
* Configuração de roteamento
* Testes de conectividade entre os dispositivos

## 🧪 Testes realizados

A comunicação entre as redes foi verificada através de testes de conectividade utilizando o comando:

```text
ping
```

Foram realizados testes entre dispositivos pertencentes às diferentes redes para verificar se o roteamento e as configurações estavam funcionando corretamente.
